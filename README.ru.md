# SmartKitchen

Языки: [English](README.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [中文](README.zh-CN.md)

SmartKitchen — это full-stack приложение на .NET 8 для управления ключевыми кухонными процессами. Оно объединяет управление рецептами, ингредиентами и запасами, недельное планирование питания, автоматическое формирование списка покупок и работу с заказами в интерфейсе Blazor Server и ASP.NET Core Web API.

Репозиторий организован как многослойное решение с отдельными проектами для фронтенда, API, доменной модели и инфраструктуры. Текущий язык пользовательского интерфейса — немецкий.

## Обзор

SmartKitchen покрывает практический рабочий цикл кухни в одном приложении:

- создание и поддержка рецептов
- управление ингредиентами и остатками
- составление недельного плана питания
- формирование списка покупок на основе плана и текущих запасов
- учет заказов и сводная аналитика на дашборде

API использует Entity Framework Core с SQLite и автоматически применяет ожидающие миграции при запуске. В проект также включены стартовые данные, поэтому приложение можно сразу использовать в локальной разработке.

## Основные возможности

- Дашборд с ключевыми метриками, последними заказами и блюдами на сегодня
- Управление рецептами с учетом времени подготовки, времени приготовления, порций, сложности и ориентировочной стоимости
- Каталог ингредиентов и учет складских остатков
- Контроль низких остатков и продуктов с истекающим сроком годности
- Недельное планирование питания
- Генерация списка покупок на основе плана питания с учетом текущих запасов
- Управление заказами
- Документация API через Swagger в режиме разработки

## Архитектура

```text
Blazor Server UI (SmartKitchen)
        |
        v
ASP.NET Core Web API (SmartKitchen.API)
        |
        v
Entity Framework Core + SQLite
        |
        v
Проекты Domain и Infrastructure
```

Решение построено как многослойная архитектура, а не как один монолитный проект. Это упрощает независимое развитие интерфейса, API, доменной модели и слоя хранения данных.

## Структура решения

```text
SmartKitchen/
|- SmartKitchen.csproj               # фронтенд на Blazor Server
|- Components/                      # Razor-компоненты и страницы
|- SmartKitchen.API/                # ASP.NET Core Web API
|- SmartKitchen.Domain/             # доменные сущности
|- SmartKitchen.Application/        # слой приложения
|- SmartKitchen.Infrastructure/     # DbContext EF Core и миграции
|- wwwroot/                         # статические ресурсы
`- SmartKitchen.sln                 # точка входа в solution
```

## Локальная разработка

### Требования

- .NET 8 SDK

### Восстановление зависимостей

```powershell
dotnet restore .\SmartKitchen.sln
```

### Запуск API

```powershell
dotnet run --project .\SmartKitchen.API\SmartKitchen.API.csproj
```

### Запуск фронтенда

```powershell
dotnet run --project .\SmartKitchen.csproj
```

### Стандартные локальные URL

- Frontend: `http://localhost:5037`
- API: `http://localhost:5011`
- Swagger: `http://localhost:5011/swagger`

Если вы запускаете solution из Rider или Visual Studio, настройте фронтенд и API как совместные стартовые проекты.

## Примечания по конфигурации

Сейчас фронтенд задает базовый адрес API напрямую в `Program.cs`:

- `http://localhost:5011`

Если вы измените порт API, обновите и эту настройку.

## База данных и стартовые данные

- Для локального хранения используется SQLite
- Строка подключения указывает на `SmartKitchen.db`
- Миграции EF Core находятся в `SmartKitchen.Infrastructure/Migrations`
- Ожидающие миграции применяются автоматически при запуске API
- Стартовые данные включают примеры ингредиентов, рецептов и складских остатков

Локальные файлы базы данных исключены из системы контроля версий через `.gitignore`.

## API

Текущая API-поверхность включает следующие маршруты:

- `api/dashboard`
- `api/recipes`
- `api/ingredients`
- `api/inventory`
- `api/mealplans`
- `api/orders`
- `api/shoppinglist`

В режиме разработки доступен Swagger для просмотра и ручного тестирования эндпоинтов.
